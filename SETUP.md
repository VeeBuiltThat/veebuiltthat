# VeeBuiltThat profile setup

Upload this structure to the `VeeBuiltThat/veebuiltthat` repository:

```text
veebuiltthat/
├── README.md
├── assets/
│   ├── dragon-logo.png
│   ├── code-create-banner.webp
│   └── veebuiltthat-banner.png
└── .github/
    └── workflows/
        └── snake.yml
```

After committing:

1. Open the repository's **Actions** tab.
2. Select **Generate contribution snake**.
3. Click **Run workflow**.
4. Wait for the workflow to finish.
5. Refresh the GitHub profile.

The generated snake is published to the `output` branch.
